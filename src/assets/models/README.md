# u2netp.onnx

U²-Netp salient object detection model by Xuebin Qin et al.,
https://github.com/xuebinqin/U-2-Net, released under the Apache License 2.0.
ONNX export as distributed by rembg (https://github.com/danielgatis/rembg).
Used by `src/lib/segment.ts` to remove busy photo backgrounds in the browser.
